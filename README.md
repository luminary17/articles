# مقالات · Articles

This repository hosts the Articles entry point for [Natiq](https://luminary17.github.io/arabic/?view=articles), the shared Arabic reading, vocabulary, and numbers app.

The extracted Arabic text for the three supplied books is stored under `docs/books/` as JSON, organized by source page. Scanned pages were transcribed with OCR and may contain recognition errors. The original PDF files are not included.
